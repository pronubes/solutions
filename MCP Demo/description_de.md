Diese Solution zeigt, wie Sie Maschinendaten über MCP verfügbar machen können.

Sie umfasst einen einfachen OPC UA Server mit simulierten Maschinendaten und REST-Triggern, bei denen der MCP-Tool-Modus aktiviert ist, um alle Maschinen aufzulisten oder alle Daten für eine bestimmte Maschine abzurufen.

Der MCP-Server ist unter `http://*:57295/mcp` erreichbar.
